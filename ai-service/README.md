# Layer 3 — Python AI Service Foundation (Milestone 3B)

This service provides the provider-independent Python foundation for analyzing `AIAnalysisBatch` packages generated by Layer 2 / Milestone 3A.

> **IMPORTANT ARCHITECTURAL NOTE**:
> This service currently produces deterministic, rule-grounded analysis responses and **DOES NOT call any external LLM APIs (OpenAI, Gemini, Anthropic, etc.)**. All processing is fully offline, reproducible, and decoupled from specific model providers.

---

- **Python**: 3.12+ (tested on Python 3.12.3)
- **pip**: Python package manager

## 5. API Endpoints

### 1. Health Check

- **Endpoint**: `GET /health`
- **Response**:
  ```json
  {
    "status": "ok"
  }
  ```

### 2. Analyze Page Batch

- **Endpoint**: `POST /analyze`
- **Request Body**: `AIAnalysisBatch` (from Milestone 3A)
- **Response**: `AnalysisResponse`
  ```json
  {
    "analysisVersion": "3B.1",
    "batchId": "batch_sess_20260817_test001_web_20260817_w01_page_002",
    "sessionId": "sess_20260817_test001",
    "websiteId": "web_20260817_w01",
    "pageId": "page_002",
    "status": "completed",
    "summary": "Analyzed 3 runtime engineering finding(s) on page https://www.example.com/ai-interns...",
    "findings": [
      {
        "findingId": "fnd_repeated_network_request_agg_evt_net_01",
        "findingType": "repeated_network_request",
        "category": "network",

        "title": "Repeated network request detected",
        "observedFact": "Observed 10 identical GET requests to https://www.example.com/api/leaderboard within approximately 3s on this page.",

  }
  ```

---

## 6. Architecture & Separation of Concerns

Every finding analysis explicitly separates:

1. **`observedFact`**: What was directly collected by the monitoring engine.
2. **`possibleInterpretation`**: Non-dogmatic technical interpretations.
3. **`requiredAdditionalContext`**: Source code or architectural context needed before taking corrective action.
