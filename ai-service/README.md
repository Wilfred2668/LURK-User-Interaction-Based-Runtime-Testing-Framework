# Layer 3 — Python AI Service Foundation & Groq LLM Integration (Milestones 3B & 3C)

This service provides the provider-independent Python foundation for analyzing `AIAnalysisBatch` packages generated by Layer 2 / Milestone 3A.

It supports dual analysis execution modes:
1. **Deterministic Mode (3B Default)**: Fully offline, rule-grounded, zero external network dependency.
2. **LLM Provider Mode (3C Groq)**: Decoupled LLM integration via `LLMProvider` abstraction using the Groq API (default model: `openai/gpt-oss-20b`).

---

## 1. Architecture & Provider Abstraction

```
AIAnalysisBatch (from Milestone 3A)
        ↓
FastAPI /analyze (Mode selection)
        ↓
AnalysisService
 ├── Mode: 'deterministic' → analyze_deterministic() (3B Engine)
 └── Mode: 'llm'           → LLMProvider Interface
                                 ↓
                           GroqProvider (Groq API)
                                 ↓
                           Prompt Construction (Page/Route isolated)
                                 ↓
                           Structured Output Validation (Pydantic)
                                 ↓
                           AnalysisResponse (Version: 3C.1)
```

## 2. Environment Variables & Configuration

Copy `.env.example` to `.env` or set environment variables:

```bash
# General
APP_NAME="Runtime Monitoring AI Service"
APP_VERSION="3C.1"
ENVIRONMENT="development"

# LLM Provider Configuration
# "none" = deterministic 3B fallback, "groq" = Groq API
LLM_PROVIDER=groq
GROQ_API_KEY=your_groq_api_key_here
LLM_MODEL=openai/gpt-oss-20b
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_TIMEOUT_SECONDS=30
```

> **SECURITY NOTE**:
> The `GROQ_API_KEY` must exist ONLY in the backend `.env` environment. It is never exposed in API responses, logs, or sent to the Chrome extension.

## 7. Changing LLM Models or Providers

To switch models on Groq:
```bash
LLM_MODEL=llama-3.3-70b-versatile
```

To add future providers (OpenAI, Anthropic, Gemini, Local):
1. Subclass `LLMProvider` in `app/providers/`.
2. Implement `analyze_batch(batch: AIAnalysisBatch) -> AnalysisResponse`.
3. Register the provider in `app/providers/factory.py`.
